On To The Next — Pilot Privacy Notice

Effective September 24, 2026

This notice describes the owner-operated On To The Next planning pilot and this static policy website. The project owner operates the pilot. It is not a public account-based travel service.

Plans and local storage

Trip information, dates, independently curated recommendations, saved activities, and details entered by the owner are stored in the pilot's local PostgreSQL database. They remain there unless changed or removed through the application's supported flows or a separately authorized maintenance action. This pilot does not promise a fixed retention period. Do not enter information about other people unless you have an appropriate reason to include it.

Optional requests to Google

When Google is activated and the owner selects a Google request, the application's server contacts Google Places API (New). Matching uses the independent recommendation's name, location, city, and Japan as the country context. Subsequent requests use a selected Google place identifier to obtain the requested context, review sample, or photo metadata/media. Private itinerary notes and travel dates are not intentionally included in those requests.

Google receives the request data, the server's IP address, the dedicated API credential, and ordinary connection metadata. The credential is sent by the server, not included in image URLs or shown in the browser. Not all information stays on this computer: optional enrichment requires these Google requests.

The application displays fetched Google content transiently. Its Google display is cleared on closing or leaving that component, or after five minutes; that is a display lifetime, not a guarantee about Google's own retention. The application does not intentionally write Google review text, fetched photos, photo resource names, or full response payloads to its database or persistent image cache. It stores the permitted Google place identifier, an app-owned identity hash and review timestamp, plus request hashes, operation type, approval label, timestamps, counts, states, and conservative usage reservations. Accounting persists across application restarts and is not refunded by deleting a trip.

Place photos are downloaded through the local server and displayed transiently. Available contributor avatars can load directly from Google image hosts in the browser after requested content is displayed. Those direct requests reveal the browser's IP address and ordinary request metadata to Google. The app suppresses the referring-page header for these images and external source links. Opening Google Maps or other source links takes you to a separate website governed by its own policies.

Google's processing is described by the Google Privacy Policy, incorporated into this notice for Google-provided services. Google may retain information under its own policy; the application's display timeout does not control that.

Other providers and policy hosting

Live Brave search, OpenAI extraction, and Viator integration are disabled for this Google-only pilot. The application does not send Google content to an AI extraction service. It performs no booking or payment transaction.

The public policy site is hosted on GitHub Pages and contains static HTML only. These pages add no analytics, forms, advertising, external fonts, or application-data uploads. GitHub states that Pages visitors' IP addresses are logged and stored for security purposes, including visitors who are not signed in. See GitHub's Pages documentation and GitHub's Privacy Statement. Visiting these policy pages does not publish or provide GitHub access to the local pilot database.

For questions about information in this owner-operated pilot, use your existing private communication channel with the project owner. No public contact address has been designated for this private pilot.
